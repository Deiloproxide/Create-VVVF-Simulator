# Tools
Here provides some tools for this mod.
</div>

## Features
- Conversion to unified IR file format.
- I18n sample file generation.
- Update YAML config format from older version.
## Run
### Requirements
No site-packages, all packages are Python Standard Library.<br>
[FFmpeg](https://ffmpeg.org/download.html) is required when converting audio to ir.<br>
[VVVF-Simulator](https://github.com/intel713/VVVF-Simulator) is required when editing YAML config.
### Usage
Run `python VVVFTools.py --help` to get usage.
